# CerChi

Un gioco geografico quotidiano: trova la capitale segreta con la **trilaterazione**.
Ogni capitale che proponi ti dice solo a che distanza si trova quella segreta; sulla mappa compare il cerchio corrispondente e con tre cerchi il bersaglio è inchiodato.

**Gioca:** https://pg-laboratorio.github.io/cerca-cerchi/

- Sfida del giorno (uguale per tutti) e partita casuale
- 195 capitali, mappa zoomabile, risultato condivisibile in emoji
- Un solo file `index.html`, nessun backend

Dati: [Natural Earth](https://www.naturalearthdata.com/) (capitali e terre emerse), [mledoze/countries](https://github.com/mledoze/countries) (nomi e bandiere).
